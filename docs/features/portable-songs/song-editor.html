txt syntax reference — legacy & @doc formats




The editor parses a single song. A line starting with === ends the song (anything after is ignored). Every line is trimmed before parsing. Format detection is per song: if a line that is exactly @doc follows the code/no header, the song is parsed as the new document format; otherwise the legacy format is used.



Inline styling (both formats)


Inside any text/lyric line, <u>…</u>, <b>…</b>, <i>…</i> mark underline / bold / italic and become styled spans. Any other markup is kept as literal text (escaped at render). Only u/b/i are recognized.



Legacy format


Line-based. A song starts with header lines, then lyric lines once a * marker appears.

Bare header lines (no keyword)


    

  • Key signature — matches [1-7]=[ABCDEFG](is|s|es|b)?, e.g. 1=Bes, 1=Ab (comma-separated alternates allowed).
    • 

  • Time signature — matches n/n, e.g. 4/4, 6/8.
    • 




Lyric markers (line starts with *)




MarkerEffect


*N (e.g. *1)normal verse, number N. If N ≤ the previous normal number, a new lyric group starts (this is how Indonesian→English re-numbered stanzas split).


*reff / *ref (opt. *reff2)refrain verse


*text (opt. *text2)spoken / instruction verse (unnumbered)


*versi <caption> / *version <caption>start a new explicit lyric group with that caption




Lines after a marker are the verse's lines. A blank line does NOT end a verse (the verse runs until the next marker or ===). // starts a comment line (ignored).

Document format (@doc)


Opt-in per song: a code <CODE> line (or no), then a line that is exactly @doc. Below @doc, each line maps to a block in written order.



Line rules


    

  • Default — a line with no leading @ or * → a p (paragraph) block, no role.
    • 

  • Tagged paragraph — one or more leading @-tags, then the text. Tags combine, e.g. @size=2.0 Big text or @size=0.5 @musical Do=C.
  
      
  
    • Role tags → p.role: @title, @title_original, @tune, @musical, @authors_lyric, @authors_music, @note, @copyright, @body, … (roles carry default formatting; title = bold + centered, etc).
      • 
  
    • Formatting tags: @size=<float> (1 = normal) and @align=<start|center|end>.
      • 
  
    

    • 

  • @scripture <osis> → a scripture block (OSIS, e.g. John.3.16; Rom.5.8; localized at render against the active Bible version).
    • 

  • @youtube <videoId> → a youtube block.
    • 

  • @row … @/row → a row block; each line between the markers becomes a p item (its own role/size/align tags apply). Items spread start → end, e.g. lyricist-left / composer-right.
    • 

  • Lyric markers *N, *ref[N]/*reff[N], *text[N], *versi/*version <caption> — same semantics + auto-grouping as legacy. Verse lines support leading @size= / @align= (per-line formatting).
    • 

  • Blank line ends the current verse (returns to paragraph mode); a following * marker reopens lyric mode.
    • 

  • Escape — a line starting with \ drops the backslash and is treated as literal paragraph text, so it can begin with *, @, //, or ==.
    • 

  • Unknown @directive → warned and skipped (not fatal).
    •
