# Developer guides

Create content for Alkitab / Quick Bible or integrate another Android app with
the Bible reader:

| Guide | What you can create |
| --- | --- |
| [Bible versions (YET)](yet.md) | Bible text with headings, parallel passages, footnotes, cross-references, and formatting |
| [Opening verses](opening-verses.md) | An app that opens Bible passages in a dialog or the main reader |
| [Song books](songs.md) | Song and hymn collections, with lyrics and optional musical information |
| [Reading plans (RPA)](reading-plans.md) | Daily reading schedules that users can download |
| [Extensions](extensions.md) | An app that receives the verses selected in the reader |

These are the guides linked from the [developer page](https://alkitab.app/developer).
These guides are maintained in this repository. Propose corrections through
a pull request against `develop`.

YET, song-book text, and RPA are authoring formats. The app reads converted
Bible versions, distributed song documents, and binary reading plans. The guides
explain the conversion or submission step for each format.

For work on the app itself, start with the repository [README](../../README.md)
and [build-system guide](../build-system.md). See [Tools](../tools.md) for desktop
converters and [Binary Formats](../binary-formats.md) for runtime file formats.

To create a reading plan in your browser, use the
[reading-plan creator](https://alkitab.app/rp/create).

Questions and content submissions: [help@alkitab.app](mailto:help@alkitab.app).
