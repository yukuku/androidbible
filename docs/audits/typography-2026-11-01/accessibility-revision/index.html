Accessibility revision • 2 November 2026

Stronger controls and clearer numeric input

Book selectors, book/chapter/verse grids, Bible and song keypad buttons, and version short names now use Medium (500). Reading content keeps its existing typography.

Initial 75-pair comparisonReview PR #375Updated Android captures

Replace next, or keep typing?

A prefilled value has a dashed border and a quieter foreground. Once a digit is entered, the field has a solid border, brighter digits, and a caret. The selected field also has an accent outline. These cues distinguish input from keypad buttons and do not rely on color alone.

Use “Show prefilled values” to see placeholders, then try each keypad. The first digit replaces a prefilled value. Further digits append while the value is valid. Switching chapter/verse keeps each field’s own input state. A four-character song code is replacement-ready because the next digit starts a new code.

Interactive design prototypes: these use your browser’s system font at Medium weight. They are not Android screenshots. Real Android captures of the current Option A implementation appear below. The final shape/color choice is open for review.

A • Recommended / implemented for review

Outlined input field

A blue outline identifies the active target. Rectangular fields contrast with the plain keypad buttons. Dashed versus solid borders show replacement versus ongoing entry.

B • Design alternative

Filled capsule

Ongoing input gains a teal fill and a light outline. The pill shape separates it from the keypad, with the strongest color cue of the three options.

C • Design alternative

Light value tile

Ongoing input uses dark digits on a light square tile, with a blue bottom edge. This makes the field easy to locate but gives it more visual weight.

Version short names or primary titles16sp Medium in both the selector and version manager
Entered chapter, verse, or song code24sp Medium in a separate outlined field
Replacement-ready valuesQuieter foreground and dashed border
Ongoing entryBrighter foreground, solid border, and caret on the active field

Bounds validation and keypad navigation behavior are retained. State descriptions are localized for screen readers. Replacement-ready digits have 6.0:1 contrast against their field; entered digits have 10.7:1 contrast. The 200% text-scale layout issues remain outside this revision.
