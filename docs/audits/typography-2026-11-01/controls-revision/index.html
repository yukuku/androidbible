Compose controls, version details, and native rollback

The latest scope keeps the shared typography styles and Compose refinements. Direct native XML/View changes have been reverted. Older reports remain historical snapshots.

Review PR #375Earlier sentence-case snapshotEarlier Medium-weight snapshotInitial proposal snapshot

Goto layout follow-up: Review the latest portrait and landscape captures. The dialer is capped at 448 dp content width, uses taller portrait digits and compact landscape digits, and Direct entry scrolls above the keyboard. The original Goto captures below predate that follow-up.

Current behavior

  • The hex label is “Warna Hex”; # is adjacent to the left of the centered input. The label is simplified consistently in all 31 UI locales.
  • Version details use a Compose bottom sheet with scrollable information and a fixed action row. Installed removable versions offer Remove at start and primary Share at end, both with icons. Download and update actions remain available where applicable. Built-in versions retain their protection from removal and unsupported file sharing.
  • Compose Bible/song number fields use a solid border when active, a dashed border when inactive, and quieter replacement-ready digits. The synthetic cursor is removed.
  • 55 native files match develop exactly. Two native helpers are removed. Existing shared themes, text appearances and keypad styles remain, so native controls can still inherit their effects. Explicit original native sizes and casing remain where the original layout defines them.

All comparison images are untouched Android captures at 720 × 1280, 320dpi and 100% system font size. The dedicated AVD uses Indonesian UI, public BIMK/KJ content, and local marker fixtures. No delete, share, sign-in, feedback or report action was submitted. The PDB conversion screen is a component fixture.

Native font tables record each TextView’s base font; inline spans can override individual runs. They list visible TextViews across the app’s windows; underlying activity text can also be present behind a modal sheet. Compose font annotations describe the named component. Keyboard, status bar and network content can differ independently of typography. The 200% layout work remains outside scope.
