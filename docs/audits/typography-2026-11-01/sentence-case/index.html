Latest typography revision • 2 November 2026

Sentence-case UI, with Option A selected

Forced uppercase styling has been removed from app controls and headings. UI labels stored in capitals now use sentence case across the existing translations. Option A, the outlined number field, is the selected design.

Selected Option A and earlier Medium-weight evidenceReview PR #375Initial 75-pair snapshot

What changed

Platform, AppCompat, Material, colored and outlined buttons preserve sentence case, including native dialog actions. Reading-plan dates/actions, version metadata labels, color-channel names, bookmark labels, and songbook All labels follow the same rule. Tune names and copyright are no longer converted to capitals in song rendering or copy/share output. The owned download catalogs override uppercase CSS.

175 localized labels or label segments were normalized in 26 locale files. Source content and identifiers such as BIMK, KJ, song suffixes, testament abbreviations, and hexadecimal values retain their proper casing.

These comparisons retain font size and weight unless the inherited native button appearance needed the shared 14sp Medium action role. Raw screenshots are unretouched. Keyboard visibility, status-bar details, and asynchronous content can differ independently of casing. Eleven baseline states were captured immediately before this change; the remaining baselines are retained earlier typography snapshots and are identified below. The song case is a production-component fixture.
